## 📌 Project Overview

**OOP-Project** is a Java desktop application that calculates the **area and perimeter** of three geometric shapes: **rectangle**, **square**, and **circle**. Built as the developer's very first programming project, it demonstrates the fundamentals of **Object-Oriented Programming (OOP)** and **Graphical User Interfaces (GUI)** in Java.

---

## ✨ Key Features

- 📏 **Area Calculation** – Computes area for rectangle, square, and circle
- 📐 **Perimeter Calculation** – Computes perimeter for all three shapes
- 🖥️ **GUI Interface** – User-friendly graphical interface for input and output
- 🧱 **OOP Design** – Classes and objects following object-oriented principles

## 🚀 How to Run

### Prerequisites
- JDK 8 or higher
- Maven 3.x

### Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/AmjadIbrahim1/OOP-Project-.git
   ```
2. Navigate to the project directory:
   ```bash
   cd OOP-Project-/Geometric_Object_Area_and_Perimeter_Calculator
   ```
3. Build the project:
   ```bash
   mvn clean package
   ```
4. Run the application:
   ```bash
   mvn exec:java
   ```
   *(or run the generated JAR from the `target/` folder)*
